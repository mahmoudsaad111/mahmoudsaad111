## 🚀 Featured projects

### 🗂️ [JobTracker](https://github.com/mahmoudsaad111/JobAppTracker) · [Live demo](https://jobapptracker.tryasp.net/dashboard)
A full-stack workspace that turns a job search into a trackable process: applications, interviews, notes, documents and a dashboard in one place, plus AI-assisted job-posting parsing, resume-to-job matching and cover-letter drafts. Comes with a Chrome/Edge extension that saves postings straight from the browser.
**Stack:** ASP.NET Core 10 · Clean Architecture · CQRS/MediatR · EF Core · SQL Server · ASP.NET Identity · OpenIddict · MCP C# SDK · Angular 17 · Docker

### 🎫 [SupportTicketSystem](https://github.com/mahmoudsaad111/SupportTicketSystem) · [Live demo](http://supportticketsystem.runasp.net/)
A helpdesk platform built to practice Domain-Driven Design: full ticket lifecycle with enforced transitions, priority-based **SLA deadlines**, a background worker that detects breaches, role-based access, notifications and CSV export. Deployed automatically with GitHub Actions.
**Stack:** ASP.NET Core 10 · ABP Framework · DDD · EF Core · SQL Server · OpenIddict · Angular · GitHub Actions · Docker

### 🏁 [RaceHub](https://github.com/mahmoudsaad111/RaceHub)
A real-time multiplayer racing game platform. Race results are processed by independent background workers through **RabbitMQ topic exchanges** (rewards, achievements, notifications) with retries and dead-letter queues, while **SignalR** pushes live updates to players.
**Stack:** ASP.NET Core 10 · RabbitMQ · SignalR · CQRS/MediatR · EF Core · SQL Server · JWT + Google Sign-In · Angular · Docker Compose

### 🎓 [University Learning Management System](https://github.com/mahmoudsaad111/University_Learning_ManagementSystem)
A backend for university life: five user roles (admin, staff, professor, instructor, student), academic structure management, courses, assignments, exams and real-time interaction.
**Stack:** ASP.NET Core · SignalR · EF Core · SQL Server · JWT · CQRS · Unit of Work / Repository · Dependency Injection

### 📋 [Project & Task Management API](https://github.com/mahmoudsaad111/Project-Task-Management-API)
A REST API for managing projects and tasks.
**Stack:** Node.js · Express
